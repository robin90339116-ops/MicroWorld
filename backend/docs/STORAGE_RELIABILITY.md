# 状态存储可靠性与当前边界

## 已交付：单进程 JSON 原子保存

`SMALLWORLD_DATABASE_URL` 未设置时，默认使用文件模式。本阶段只改变文件模式，没有部署华为云数据库。

- 保存时先验证输出是 JSON 对象，再写同目录唯一临时文件，使用 0600 权限；同步文件到磁盘后原子替换目标，并同步父目录。
- 临时文件写入、文件同步或替换失败时，旧文件保持原样；自动清理本次创建的临时文件，不清理其他业务文件。
- 目标文件已替换但父目录同步失败时，返回 `STORAGE_COMMIT_UNCERTAIN`。此时新数据可能已保存，客户端应先查询结果；不能把错误解释为“操作一定没发生”。幂等重试仍须由业务接口保证。
- 启动时已有文件为空、JSON 损坏或根结构无效，不再用种子数据覆盖，而是拒绝启动。运行中读取异常、文件消失或损坏，也不自动重建。
- 运行中存储异常返回 HTTP 503 及明确错误码，不返回文件原文。符号链接不作为状态文件使用。
- 初始化只在启动时路径不存在的情况下生成初始数据；并发首次创建使用排他发布，不覆盖其他已创建文件。

## 运维注意

- 改变行为：过去空文件会被自动重置，现在会报错。遇到错误请先停止业务写入，保留故障文件，核对磁盘、权限和路径，再从经过验证的备份恢复。不要删除故障文件来“修复登录”。
- 当前没有自动备份、数据库迁移或磁盘损坏修复。原子替换不等于备份；必须另行配置备份并验证恢复。
- 路径在进程完全重启前已经消失时，本程序无法区分首次部署和数据文件丢失，仍会初始化。部署环境必须固定数据路径、保留持久卷并检查备份；不要把本实现视为防止人为删除的保证。
- 不支持多个进程同时写同一 JSON。原子写入只避免半份文件，不解决多个读改写快照相互覆盖；业务幂等和并发控制仍需独立保障。
- 数据文件目录必须由可信服务账号管理；临时文件和原子替换依赖同一文件系统及其 fsync/rename 语义。

## 数据库模式：事务改造及隔离 PostgreSQL 16 验收通过

- HTTP 请求正文先完整读取并限制为原有 1MB 上限与 10 秒读取期限，再开始数据库事务，避免慢上传长期持锁。
- 请求取得 singleton 行锁并读取最新数据；业务读写限于 AsyncLocalStorage 请求上下文，禁止绕过事务直接读写。脏状态在事务中 UPDATE，收到 COMMIT 确认后才发送缓存的 HTTP 响应，注册令牌也不会提前发送。
- 业务服务出现 5xx 时回滚，正常业务拒绝（4xx）仍可提交该请求已记录的状态。连接/查询失败返回 503；提交回执丢失返回 STORAGE_COMMIT_UNCERTAIN，不能据此推断事务一定未执行。不会自动重放业务操作；客户端必须先查原结果或使用幂等接口。
- 移除进程级状态缓存与后台忙循环。每次请求重新读取数据库，行锁串行化参与同一表的请求；这不是跨服务分布式事务。所有请求共享整份 JSON 行，吞吐量有限，后续应按业务实体拆表。
- 连接与查询超时 5 秒、行锁等待 3 秒、事务空闲 10 秒。停止服务时先停止接收请求并等待在途请求，再关闭连接池；15 秒仍无法退出时以失败退出，不能伪报落库成功。
- TLS 默认校验证书；私有 CA 显式配置。连接 URL 中 SSL 覆盖参数被拒绝，表名和连接池大小严格校验。不再用 huawei-gaussdb 健康标记冒充云连接；当前驱动返回 postgres。
- `npm run smoke:db` 必须提供数据库地址和 pg 驱动，始终使用随机隔离测试表并在结束时清理该表。禁止直接带数据库地址运行普通 smoke，防止污染业务表。

已安装 pg 并提交依赖锁文件；本机仍没有可运行的 PostgreSQL 或 Docker，但 GitHub Actions 已完成真实 PostgreSQL 16 隔离验收。数据库单元测试仍使用模拟连接与行锁；实库证据来自独立的 test:db 与 smoke:db，不能混为同一类测试。openGauss 须单独验证，不因协议相似就声称支持。
