## 第一阶段：日常使用（代码修复中，尚待真机验收）

- 兴趣接口读取 `topics`；分类来自后端，搜索与分类参数接入，过期请求不覆盖最新筛选结果。
- 探索列表接入搜索，加载、失败重试和空列表不再显示默认地点卡片。
- 私聊加载真实消息列表并定时刷新，离开页面停止轮询；错误时保留草稿。
- 发送按钮防连点；同一草稿重试使用相同消息标识，后端拒绝冲突、避免重复写入。
- 登录令牌及安装标识使用鸿蒙 Asset 安全存储；不保存密码，不在健康检查或其他候选服务器传递令牌。
- 恢复会话会重新向原服务器验证；401 清理当前会话；退出要求服务端撤销成功并清除安全存储。
- 小世界名称、地点、主题、可见性绑定输入；创建失败留在表单；商家评价文本绑定提交。
- 聊天列表、历史、发送、好友详情、动态、连接请求增加账号范围校验；双方拉黑均禁止交互。

### 数据兼容性

旧 `friends` / `chats` 种子记录没有所属账号，不能安全推断归属，因此不展示给真实账号，未删除原记录。
真实好友记录需 `ownerId`，双人聊天需 `participantIds`。下一阶段的双方 NFC 确认流程需创建该结构。
不自动把全局演示人物迁移为用户好友。

### 验证命令

- 后端：`npm test`；隔离文件模式：`SMALLWORLD_DATABASE_URL= SMALLWORLD_CHAIN_PROVIDER=certificate npm run smoke`。
- 鸿蒙：使用 DevEco 安装目录内的 Node、Hvigor，指定 `DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk`，执行 `--mode module -p product=default -p module=entry@default assembleHap --no-daemon`。
- 编译和签名成功不等于运行验收。NFC 设备能力和第三方地图依赖仍有编译警告。
