## 第二阶段：个人碰一碰（代码与本地验证，不等于双机验收）

- 状态：waiting → awaiting_host → confirmed；另有 cancelled / expired / superseded。
- 读取方提交令牌和挑战并确认；被碰方必须使用本机 HCE 观察到的同一挑战显式确认。
- 首次及后续碰面均要求双方确认，暂不启用熟人免确认；同一对用户每 UTC 日只发放一次积分/好感度奖励。
- 两端轮询各自可见的会话结果，共享 proofId / chatId；取消、过期不产生奖励。
- 按账号建立两条好友记录和一个双人会话；奖励各自保存，可重复查询且不重复发放。
- 历史接口剔除设备标识、令牌和挑战；界面读取真实历史。
- 当前验证级别为 mutual-client-reported-nfc，hardwareVerified / gpsVerified 均为 false；不允许据此绕过硬件认证地点评价门槛。
- 徽章仍为未上链的数字凭证，不声称真实 NFT 铸造完成。
- 确认路由在读取请求正文之后再取得数据快照，避免单进程并发重试覆盖结果；多实例数据库事务仍待第四阶段。
- 真机清单：首次双方确认、取消与超时、重复读取、已是好友复次碰面、双方历史和奖励一致、跳转聊天、断网后恢复结果。

### 重启恢复

- 安全存储记录账号、后端地址、会话、角色、本机 NFC 挑战和用户操作意图；不会跨账号或后端恢复。
- 发起、读取、确认前写入检查点；写入失败不发送确认。存储写入串行化，旧会话清理不会删除新会话记录。
- 启动登录恢复或重新登录后查询原服务器；个人碰一碰记录页也提供手动恢复入口。
- 不因本机检查点过期就丢弃结果：服务器可能在截止前已完成确认，恢复时只读取奖励快照，不再次发放。
- 被碰方等待确认时仍需显式操作，检查点不能替代双方确认。读取方尚未绑定的会话返回 404 时保留本机读取记录，要求重新核对本人后提交。
- 取消意图跨重启保留；网络失败不显示服务端已取消。已完成但本地记录清理失败时保留成功结果，后续恢复仍是只读核对。
- 退出页面为取消；组件销毁只停止本机 NFC 和轮询，保留恢复记录。
- 限制：会话创建响应到达并写入检查点前即被杀进程时无法恢复该未知会话 ID；该孤立会话由服务端两分钟有效期失效，不会自动创建好友或奖励。

## 第三阶段 A：关闭模拟支付与商品评价资格漏洞

- 支付接口不再根据客户端金额直接创建 paid 订单；在支付渠道未接入时返回 503 / PAYMENT_NOT_CONFIGURED，不写入订单或改变碰触状态。
- 商品评价返回 403 / VERIFIED_PAYMENT_REQUIRED；历史模拟 paid 订单、客户端成功标志和重复请求均不能解锁评价。旧数据保留，不删除、不冒充真实交易。
- 前端移除固定金额模拟支付调用；入口明确显示未开通及不会扣款，商品评价按钮禁用。服务端同样拦截，不能通过绕过界面解锁。
- 新增支付安全回归测试，覆盖伪造支付成功、异常金额、重复请求、历史模拟订单、账号隔离和零写入；HTTP smoke 改为验证拒绝及无新增订单/商品评价。
- 此子阶段仅修复支付误判，不代表真实收款已接入。商家身份、真实 NFC 凭证与地点评价奖励仍未完成安全改造，当前商家到店演示不得用于生产发放权益。
- 后续接入必须包括服务端商品/金额确定、支付平台验签与查单、订单绑定、幂等回调及退款资格处理；不得只添加客户端支付成功标志重新开放。
- 本次验证：22 项后端单元测试通过；隔离 JSON 模式 HTTP smoke 通过；鸿蒙 assembleHap（含 SignHap）通过。既有 NFC 设备兼容性及地图依赖警告仍在，未进行真机支付验收。

## 第三阶段 B：演示评价与奖励幂等（非真实到店凭证验收）

- 地点评分必须为数值型 1–5 整数；标签最多 8 个、每个 1–24 字，评论最多 240 字。非法输入拒绝，不自动改成五星或静默截断。
- 相同评价重试返回 200 及原评价/奖励快照；不同内容重复提交返回 409。标签排序与重复标签不构成新评价。旧评价无奖励快照时返回 null，不重新铸造或补发。
- 奖励快照保存于评价与碰触记录，可在查询中恢复。余额为该次结算快照，不冒充当前余额。
- 暂定同账号、同地点每 UTC 自然日只奖励一次；新碰触可记录评价但奖励为零，界面不再兜底显示 +5 或虚构徽章。此为防刷默认规则，业务时区/活动策略后续可配置化。
- 重复打卡不刷新原打卡时间，也不会把已评价/已领奖状态回退。paid/rewarded 等状态不能替代有效打卡时间。
- 商家变更路由在完整读取正文后取得最新数据快照；用户设备字段取登录会话，忽略正文伪造的用户设备。仅覆盖单进程，尚无多实例数据库事务保证。
- 删除前端“已认证商家”“GPS 匹配”等虚假成功提示，入口明确为演示；新记录及旧记录的公开表示均不声称硬件/GPS 核验。
- **仍未完成：商家可信登记、真实 NFC 凭证交换、到店真实性和生产权益资格。现有演示 API 仍能创建演示打卡与演示积分，不应对外作为真实权益服务上线。**
- 新增重启快照恢复、重复与冲突提交、跨账号隔离、输入校验、打卡状态不回退、跨碰触每日限额及路由读取顺序测试；HTTP smoke 覆盖 6 路并发重试。
- 验证结果：31 项后端单元测试通过；隔离 JSON 模式 HTTP smoke 通过；鸿蒙 assembleHap（含 SignHap）通过，既有设备兼容性和地图依赖警告仍在。无真机 NFC / 商家身份验收结论。
