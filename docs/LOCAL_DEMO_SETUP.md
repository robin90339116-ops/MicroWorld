# 本地演示与配置安全

## 启动方式

以下命令从 `backend/` 执行，使用 Node.js 22 与 `npm ci` 安装的依赖。后端最低 Node 版本声明已与现有 Node 22 容器及 CI 对齐；旧 Node 18 环境需升级后使用。本轮不改变 DevEco 自带的构建 Node。

| 命令 | 配置来源 | 用途 |
|---|---|---|
| `npm run start:example` | `.env.example` + 进程环境变量 | 本机开发示例，默认回环地址、文件存储、未上链凭证 |
| `npm run start:local` | 自己创建的 `.env` + 进程环境变量 | 本机自定义配置；文件缺失则启动失败 |
| `npm start` | 仅进程环境变量 | 保留原部署入口，不自动读取 `.env`；默认监听全部网卡 |

使用编辑器将 `.env.example` 内容保存到同目录 `.env`，再按需填写。不要覆盖已有 `.env`。Node 的 `--env-file` 不会覆盖已存在的环境变量；测试前确认终端没有继承生产数据库或链配置。不要在聊天、截图或日志中打印这些值。

文件模式的 `data.json` 保存账号及会话状态，不能作为作品集素材上传。数据库模式的设置、TLS 和备份见后端对应文档；本机启动成功不代表华为云部署完成。

## 真机连电脑

1. 手机与电脑处于可互通的受信网络；仅需要真机访问时，在本地 `.env` 设置 `SMALLWORLD_BACKEND_HOST=0.0.0.0`。
2. 在前端 `Index.ets` 的 `API_BASE_CANDIDATES` 中使用电脑可达地址。不要把手机的 `localhost` 当作电脑。
3. 限制防火墙允许的来源，不做公网端口转发。HTTP 仅供受信测试网络；正式服务必须部署 HTTPS。
4. 使用自己的测试账号与两个不同设备。商家链路还需管理员登记，参见 [商家终端配置](../backend/docs/MERCHANT_TERMINAL_SETUP.md)。

示例配置不开放真实支付；更换环境变量也不能绕过服务端支付核验。MapKit 需要独立 AGC 服务配置、匹配签名与真机验证。AR/AI 示例不是实时导航或生成结果。

## 提交与公开检查

- `.env`、`.env.*`（示例除外）、私钥、签名容器、业务数据和 AGC 文件应留在本机。
- `.gitignore` 只防止未跟踪文件被意外加入，不会移除已跟踪内容或清理历史。
- 项目的 `build-profile.json5` 曾被跟踪并含签名密码字段；现已移除该路径的分支历史，使用 `build-profile.example.json5` 模板。不要重新提交本机配置；公开前仍需处理凭据与历史副本，见 [签名与历史清理](SIGNING_SECURITY.md)。
- 若发现凭据曾提交，应先吊销/轮换，再协调历史清理。不要仅删一行就认为泄露已解决。
- 本轮不替换签名、不删除证书、不改访问权限，也不重写 Git 历史。新增忽略规则不代表仓库已通过完整秘密审计。

## 回归与演示边界

```bash
npm test
SMALLWORLD_DATABASE_URL= SMALLWORLD_CHAIN_PROVIDER=certificate npm run smoke
```

自动回归使用隔离测试资源，不替代双机演示。录屏前按 [演示分镜](../portfolio/demo.md) 检查账号、双方确认、取消、重复提交、断网恢复及脱敏；真实视频缺失时只展示已标注的流程示意。
