# SmallWorld 完整前端设计与验收清单

> 基线日期：2026-06-21  
> 目标：在不改变“真实地点、真实见过、兴趣连接”核心规则的前提下，把现有演示页面收口为一套一致、完整、可真机演示的 HarmonyOS 移动端前端。

## 1. 设计原则

- 中文界面，品牌统一使用 `SmallWorld`。
- 视觉关键词：城市地图、轻 AR、真实地点、低压力、高可信。
- 不使用陌生人滑卡、颜值优先、在线状态催促等普通交友产品表达。
- 重要关系信息始终说明来源：地点、活动、任务、小世界或共同兴趣。
- 主色使用深绿，青绿表示真实/安全，橙色表示活动与提醒，紫色只作为虚拟世界辅助色。
- 页面背景使用中性浅灰，卡片使用白色，减少当前大面积米黄色造成的陈旧感。
- 所有主操作、返回、筛选、切换、输入、加载、空状态和错误状态必须可见且可操作。
- 底部导航固定贴合系统安全区，使用 HarmonyOS 透明玻璃效果。
