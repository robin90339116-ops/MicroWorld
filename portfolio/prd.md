# 精简 PRD｜个人连接与商家到店评价

[返回展示首页](README.md) · 版本：展示版 1.0 · 2026-09-10

本文依据当前代码与验收记录整理，不是所有历史原型页面的完整规格。验收条件是要求；是否已经通过须看 [证据表](evidence.md)。

## 目标与范围

目标：让双方明确表达建立联系的意愿，让用户在失败或重试后仍能查询原结果；将商家到店评价与未经核验的消费评价分开。

本版包含：个人会话、双方确认、连接/聊天、奖励与历史恢复；商家登记终端、动态凭证、打卡、地点评价与结果恢复。

本版不包含：真实收款、商品评价开放、静态门贴可信认证、硬件防中继证明、真实上链、AR/智能导游正式能力。

## P1｜个人碰一碰

**用户故事：**作为活动参与者，我希望确认对方及本次相遇后再建立联系，并在网络异常后查回结果，而不是重复建关系。

| 阶段 | 用户与系统行为 | 验收要点 |
|---|---|---|
| 准备 | 两端登录各自账号，进入个人碰一碰；一端广播、一端读取 | 不支持 NFC、权限或系统能力异常时不能进入假成功 |
| 等待 | 服务端创建限时会话 | 当前有效期两分钟；过期、被替代、取消均不可新建连接 |
| 读取与确认 | 读取方核对本人并提交；被碰方使用本机观察到的挑战显式确认 | 首次和熟人复次均需双方确认；不得互传登录令牌 |
| 完成 | 双方获得各自可见的结果、好友关系及共享聊天 | 同次确认重试返回原结果，不重复创建聊天或发奖 |
| 恢复 | 读取账号及后端绑定的安全检查点，先查询原会话 | 不跨账号恢复；已完成只查结果；未确认不自动替用户同意 |

当前会话主要状态为 waiting → awaiting_host → confirmed，终止分支包括 cancelled / expired / superseded。状态名用于定位实现，不要求用户理解英文状态码。

**奖励规则：**同一对用户每 UTC 自然日最多获得一次对应积分/好感度奖励；当前合格场景各 +6。业务时区后续需明确。纪念记录默认不上链，不称作已铸造 NFT。

**已知窗口：**会话创建响应尚未保存时进程被杀，客户端可能不知道新会话 ID；依靠有效期失效处理，不宣称所有时间点均可恢复。

## M1｜商家到店评价

**用户故事：**作为消费者，我希望打卡后评价实际地点，并看见本次评价结果；作为商家，我希望设备登记和交互进度有明确归属，而不是任何人都能冒充商家。

| 阶段 | 准入与规则 | 异常处理 |
|---|---|---|
| 登记 | 服务器登记账号、设备与地点，客户端不能自助升权 | 缺失、异常或撤销登记拒绝发起/兑换 |
| 交换 | 商家动态会话与两端挑战对应；服务端确定地点 | 未观察到匹配挑战时等待/重试原凭证，不能虚构到店 |
| 打卡 | 有效动态凭证兑换成功，首次打卡受 20 分钟窗口约束 | 重试不刷新原时间、不将已评价状态回退 |
| 地点评价 | 完成有效打卡；星级为 1–5 整数 | 标签最多 8 个、各 1–24 字；文本最多 240 字；非法输入拒绝 |
| 结果 | 同内容重试返回原评价及奖励快照 | 改变内容重复提交返回冲突，不重新发奖 |

奖励当前按同用户、同地点、每 UTC 自然日一次限制；合格评价 +5，非合格奖励不得由前端兜底显示。商家进度不暴露消费者奖励余额、令牌或评价文本。

支付尚未接入，支付操作返回 PAYMENT_NOT_CONFIGURED；商品评价由服务端以 VERIFIED_PAYMENT_REQUIRED 拦截。普通静态门贴不等于当前动态商家终端方案。

## 共用异常体验

| 情况 | 对用户的解释原则 | 系统要求 |
|---|---|---|
| 网络中断/结果未知 | “暂未确认结果，请查询或重试原操作” | 不显示已取消/已领奖，不创建替代奖励 |
| 请求重复 | 返回本次原结果 | 业务幂等，而非只禁用按钮 |
| 会话过期 | 告知会话失效，重新发起需要用户选择 | 不能依据本机倒计时删除可能已完成的结果 |
| 退出页面 | 区分取消业务与停止本机扫描 | 服务端取消以真实响应为准 |
| 无数据 | 明确暂无记录 | 不注入演示朋友或伪造奖励 |

上述解释原则为验收参考，不表示每条示例文案已经逐字部署。

## 真机发布门槛

- 两端实际 NFC 交换与双方确认成功；任一方拒绝不会建立关系。
- 快速重复操作、超时、断网、杀进程、切换账号后结果可解释、奖励不重复。
- 核心页面顶端排列、导航返回、键盘遮挡、字号与玻璃效果逐页检查。
- 实际服务器地址、定位/地图权限及错误提示均核对，不能用演示坐标冒充真实位置。
- 真实支付与商家运营资质未验收前，不发放生产交易权益；真实上链未验收前不宣称铸造成功。
